# Intent: Integer Addition Module

## Problem Statement
We need a robust, deterministic arithmetic addition function in `src/app.py` capable of summing two integers.

## Scope
- Implement `add(a: int, b: int) -> int` in `src/app.py`.
- Must handle positive and negative integers.

## Acceptance Criteria
- [ ] `add(2, 3) == 5`
- [ ] `add(-1, 1) == 0`
- [ ] `add(0, 0) == 0`
